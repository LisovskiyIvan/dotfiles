# Руководство по разработке и публикации игр на Яндекс Игры (`yandex-games`)

Памятка для разработчика по интеграции с Yandex Games SDK v2, настройке лидербордов и деплою через консоль.

---

## 🏆 1. Настройка Таблицы Лидеров (Leaderboards) в Консоли

Если игра отправляет счет в лидерборд (например, `submitScore('best', score)`), его **необходимо создать вручную в Консоли разработчика**:

1. Откройте [Консоль разработчика Яндекс Игр](https://yandex.ru/dev/games/console/).
2. Перейдите в вашу игру (или черновик) → выберите вкладку **«Лидерборды»** в левом меню.
3. Нажмите **«Добавить лидерборд»** и заполните поля:

| Поле в консоли | Что указывать | Важные нюансы |
| :--- | :--- | :--- |
| **Техническое название (ID)** | `best` *(или имя из переменной `LEADERBOARD_ID` в коде)* | ⚠️ **КРИТИЧНО**: должно совпадать **символ в символ** (с учетом регистра). Если в коде `best`, а в консоли `Best` или `score`, вызов `lb.setLeaderboardScore()` молча не запишет очки без ошибки! |
| **Название (Русский)** | `Рекорд` *(или Топ игроков)* | Отображается игрокам в интерфейсе платформы. |
| **Название (English)** | `Best Score` *(или Top Players)* | Отображается игрокам с английским языком. |
| **Тип** | `Числовое` (Numeric) | Для большинства игр (очки, монеты, этажи). Для таймеров/гонок — `Время`. |
| **Сортировка** | `По убыванию` | Больше очков = выше место в таблице. Для таймеров — `По возрастанию`. |
| **Скрытие имени** | Включено (галочка) | Позволяет пользователям играть анонимно. |

> **Ограничение платформы**: Лидерборды работают **только для авторизованных игроков**. Для гостей SDK возвращает ошибку, поэтому в коде вызов обернут в `try/catch`, а рекорд локально сохраняется в `localStorage`.

## 🚀 2. Главные капканы и правила деплоя на Яндекс Игры

### 1. Сборка архива (`*-yandex.zip`)
- ❌ **Капкан №1**: `index.html` лежит внутри папки (например, `my-game.zip/dist/index.html`). Модерация отклонит игру мгновенно!
- ✅ **Как правильно**: `index.html` должен быть **строго в корне zip-архива** (`my-game.zip/index.html`).
- Команда сборки в `package.json`:
  ```bash
  rm -rf dist && vite build && cd dist && zip -rq ../game-yandex.zip .
  ```
- В `vite.config.ts` обязательно должно быть `base: './'`. Игры вставляются в iframe из подкаталогов S3-бакетов. Абсолютные пути (`/assets/...`) ведут к белому экрану и 404 ошибкам.
- **Никаких внешних ссылок (CDN)**: шрифты (WOFF2/TTF), текстуры и звуки должны быть упакованы в архив. Единственный разрешенный внешний скрипт — `/sdk.js`.

---

### 2. Вкладка «Общее» в Консоли
- [ ] **Чекбокс «Игра использует облачные сохранения»**: **ОБЯЗАТЕЛЬНО включить**, если игра использует `player.setData()` / `player.getData()`. Без этой галочки платформа блокирует облачные вызовы.
- [ ] **Поддерживаемые платформы**: отметить `Десктопные`, `Мобильные` (и `Планшеты`).
- [ ] **Ориентация**: для адаптивных игр — `Любая`.
- [ ] **Возрастной рейтинг**: `0+` (если нет реалистичного насилия, крови или азартных игр).
- [ ] **Языки игры**: добавить `Русский` и `Английский`. Модератор переключает язык аккаунта Яндекса и проверяет смену языка игры через SDK (`ysdk.environment.i18n.lang`).
- [ ] **Ключевые слова**: через запятую, строго **до 100 символов** с пробелами.
- [ ] **Комментарий разработчика** (до 2048 символов): скопировать чеклист соблюдения требований модерации (LoadingAPI.ready, GameplayAPI, реклама 60с, i18n SDK).

---

### 3. Реклама и звуки (Autoplay Policy)
- **Звук**: игра **не должна** издавать звуки до первого клика или тапа пользователя (иначе блокировка браузером и отказ модерации).
- **Полноэкранная реклама (`showFullscreenAdv`)**:
  - Кулдаун **не чаще 1 раза в 60 секунд**.
  - **Запрещено** показывать рекламу при первом открытии игры. Показывать только на паузах (Game Over, рестарт, победа).
  - Игра и звук должны вставать на паузу во время рекламы.
- **Видео с вознаграждением (`showRewardedVideo`)**:
  - Показывается **только** по кнопке игрока («Возродиться», «Подсказка»).
  - Награда выдается **строго** в коллбэке `onRewarded`.

---

### 4. Промо-материалы (`yandex/`)
- `icon_512.png` — строго PNG 512×512 px.
- `cover_800x470.png` — строго PNG 800×470 px.
- Скриншоты — альбомные десктопные (1280×720 / 1920×1080) и портретные мобильные (720×1280).
- Видео геймплея — MP4 H.264 (горизонтальное 16:9 и вертикальное 9:16).

