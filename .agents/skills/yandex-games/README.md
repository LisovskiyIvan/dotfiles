# Руководство по разработке игр на Яндекс Игры (`yandex-games`)

Памятка по интеграции с Yandex Games SDK v2, языку, сейвам, звуку, рекламе, лидербордам и деплою.
Сторонние ассеты (тексты, иконка, обложка, скриншоты, видео, пакет `yandex/`) — в скилле `yandex-assets`.

---

## 🏆 1. Настройка Таблицы Лидеров (Leaderboards) в Консоли

Если игра отправляет счет в лидерборд (например, `submitScore('best', score)`), его **необходимо создать вручную в Консоли разработчика**:

1. Откройте [Консоль разработчика Яндекс Игр](https://yandex.ru/dev/games/console/).
2. Перейдите в вашу игру (или черновик) → выберите вкладку **«Лидерборды»** в левом меню.
3. Нажмите **«Добавить лидерборд»** и заполните поля:

| Поле в консоли | Что указывать | Важные нюансы |
| :--- | :--- | :--- |
| **Техническое название (ID)** | `best` *(или имя из переменной `LEADERBOARD_ID` в коде)* | ⚠️ **КРИТИЧНО**: должно совпадать **символ в символ** (с учетом регистра). Если в коде `best`, а в консоли `Best` или `score`, вызов `lb.setLeaderboardScore()` молча не запишет очки без ошибки! |
| **Название (Русский)** | `Рекорд` *(или Топ игроков)* | Отображается игрокам в интерфейсе платформы. |
| **Название (English)** | `Best Score` *(или Top Players)* | Отображается игрокам с английским языком. |
| **Тип** | `Числовое` (Numeric) | Для большинства игр (очки, монеты, этажи). Для таймеров/гонок — `Время`. |
| **Сортировка** | `По убыванию` | Больше очков = выше место в таблице. Для таймеров — `По возрастанию`. |
| **Скрытие имени** | Включено (галочка) | Позволяет пользователям играть анонимно. |

> **Ограничение платформы**: Лидерборды работают **только для авторизованных игроков**. Для гостей SDK возвращает ошибку, поэтому в коде вызов обернут в `try/catch`, а рекорд локально сохраняется в `localStorage`.

## 🚀 2. Главные капканы и правила деплоя на Яндекс Игры

### 1. SDK подключён

- `<script src="/sdk.js">` в `<head>` **до** бандла игры; `YaGames.init()` → `LoadingAPI.ready()` после загрузки ассетов → `GameplayAPI.start()/stop()` вокруг активного геймплея.
- Шаблон-обёртка: `templates/yandex.ts` (`init`, `loadingReady`, `gameplayStart/Stop`, `bindLifecycleHandlers`).

### 2. Язык — только `ysdk.environment.i18n.lang`

- `ru` / `en` из SDK; оверрайд `?lang=ru` / `?lang=en` для тестов; фолбэк `navigator.language` → `ru`.
- Словари и `data-i18n` перерендер: `templates/i18n.ts`.

### 3. Сейвы — прогресс, уровни, настройки через `ysdk.getPlayer()`

- `loadData` / `saveData`: сначала `localStorage`, затем облако (`getData` / `setData`) при `isPlatform && player`, всё в `try/catch`.
- Если есть `setData`/`getData` — включить чекбокс **«Игра использует облачные сохранения»**.

### 4. Звук (пауза при потере фокуса и рекламе)

- No autoplay: ни звука до первого клика/тапа; `AudioContext` создаётся лениво.
- `visibilitychange` + `blur`/`focus` + `game_api_pause`/`resume` → одна пара `sound.pauseAll()` / `sound.resumeAll()` (шаблон `templates/sound.ts`).

### 5. Реклама

- **Interstitial**: только на естественных паузах (Game Over, рестарт, меню), кулдаун ≥ 60 сек, никогда при первом открытии.
- **Rewarded**: **всегда спрашивать пользователя** — кнопка с понятным оффером + диалог (`confirmAndShowRewarded`); награда строго в `onRewarded`.
- На время рекламы игра и звук встают на паузу (внутри обёртки).

### 6. Сборка архива (`*-yandex.zip`)

- ❌ **Капкан №1**: `index.html` лежит внутри папки (например, `my-game.zip/dist/index.html`). Модерация отклонит игру мгновенно!
- ✅ **Как правильно**: `index.html` должен быть **строго в корне zip-архива** (`my-game.zip/index.html`).
- Команда сборки в `package.json`:
  ```bash
  rm -rf dist && vite build && cd dist && zip -rq ../game-yandex.zip .
  ```
- В `vite.config.ts` обязательно `base: './'`. Абсолютные пути (`/assets/...`) ведут к белому экрану и 404.
- **Никаких внешних ссылок (CDN)**: шрифты, текстуры и звуки упакованы в архив. Единственный разрешенный внешний скрипт — `/sdk.js`.
