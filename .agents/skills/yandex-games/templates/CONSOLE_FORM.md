```text
Технический чеклист интеграции Yandex Games SDK v2:

2. Геймплейные события: отправляются сигналы GameplayAPI.start() при начале активной игры и GameplayAPI.stop() при паузе, Game Over и перед показом рекламы.
3. Реклама:
   — Межстраничная (Fullscreen Adv): вызывается только на естественных паузах (рестарт уровня, экран поражения) с кулдауном не чаще 1 раза в 60 секунд. Активный геймплей не прерывается.
   — Реклама с вознаграждением (Rewarded Video): инициируется исключительно нажатием игрока на соответствующую кнопку («Возродиться» / «Подсказка»). Награда начисляется строго по коллбэку onRewarded.
   — Звук и анимация глушатся на время показа рекламы.
4. Локализация: поддерживаются русский (ru) и английский (en) языки. Язык выбирается автоматически по ysdk.environment.i18n.lang (п. 2.14 требований).
5. Облачные сохранения: сохраняется рекорд и прогресс игрока (player.setData / getData). Для неавторизованных пользователей работает кэш в localStorage.
6. Пакет и ресурсы: все ассеты (шрифты, текстуры, процедурный Web Audio звук) находятся внутри архива, внешних сетевых запросов нет. Относительные пути (base: './') соблюдены.

Будем рады оперативной обратной связи!
```

## 5. Настройка Таблицы Лидеров (Лидерборды) в Консоли

Если игра отправляет очки в лидерборд (например, вызов `submitScore('best', score)`), его **нужно создать руками в Консоли разработчика**:

1. Перейдите в Консоль: `https://yandex.ru/dev/games/console/` → выберите игру → вкладка **«Лидерборды»**.
2. Нажмите **«Добавить лидерборд»**.
3. Заполните поля:
   - **Техническое имя (ID)**: строго совпадает с кодом (`best`, `score` или имя из `LEADERBOARD_ID`).
     > ⚠️ **ВНИМАНИЕ**: Если в коде написано `best`, а в консоли заведено `Best` или `Leaderboard`, SDK молча пропустит отправку счета без ошибки!
   - **Название**:
     - Вкладка Русский: `Рекорд` (или `Топ игроков`).
     - Вкладка English: `Best Score` (или `Leaderboard`).
   - **Тип**: `Числовое` (Numeric) для очков / уровней; `Время` для таймеров.
   - **Сортировка**: `По убыванию` (чем больше очков, тем выше) или `По возрастанию` (для времени).
   - **Разрешить игрокам скрывать имя**: включить.
4. **Важно знать**:
   - Лидерборд сохраняет счет **только авторизованным пользователям** Яндекса. Для гостей вызов в коде перехватывается в `try/catch` и пишется в `localStorage`.

## 6. Чеклист перед деплоем и отправкой на модерацию

- [ ] **Архив `*-yandex.zip`**:
  - `index.html` лежит **строго в корне архива** (не внутри `dist/`!).
  - Сборка выполнена с `base: './'` (все пути в HTML/JS относительные).
  - Нет внешних запросов (шрифты, скрипты, звуки запакованы внутри).
  - Размер архива ≤ 100 МБ.
- [ ] **Вкладка «Общее»**:
  - Отмечен чекбокс **«Игра использует облачные сохранения»** (если есть `player.setData/getData`).
  - Выбраны платформы: `Десктопные`, `Мобильные` (и `Планшеты`).
  - Ориентация: `Любая` (для адаптивных) или `Альбомная` / `Портретная`.
  - Возрастной рейтинг: `0+` (если нет крови/насилия).
  - Языки: добавлены `Русский` и `Английский`.
  - Ключевые слова: строго ≤ 100 символов через запятую.
  - Комментарий разработчика: скопирован текст из Раздела 1 (до 2048 символов).
- [ ] **Промо-материалы**:
  - Загружена иконка `yandex/icon_512.png` (PNG 512×512).
  - Загружена обложка `yandex/cover_800x470.png` (PNG 800×470).
  - Загружены десктопные скриншоты (минимум 2–4 штуки, альбомные).
  - Загружены мобильные скриншоты (минимум 1–2 штуки, портретные).
  - Загружены промо-видео геймплея (`gameplay_horizontal.mp4` и `gameplay_vertical.mp4`).
- [ ] **Тестирование черновика**:
  - Звук не воспроизводится до первого клика игрока (Autoplay Policy).
  - Полноэкранная реклама не показывается на старте игры (кулдаун ≥ 60 секунд).
  - Rewarded видео начисляет бонус только при полном досмотре.
  - На время показа рекламы игра и звуки встают на паузу.
  - При переключении языка в профиле Яндекса интерфейс игры переключается.
