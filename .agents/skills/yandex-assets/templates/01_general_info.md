# Вкладка «Общее» — скопировать поля в консоль разработчика

> Машиночитаемый формат: каждый `### заголовок (≤ лимит)` + ```text блок.
> Не переименовывать заголовки и не убирать fence — иначе `validate_yandex_submission.py` не проверит лимиты.

## Поля консоли

- **Версия**: `0.0.0.1`
- **Поддерживаемые платформы**: Десктопные, Мобильные, Планшеты
- **Ориентация**: Любая (или Альбомная / Портретная)
- **Рекомендуемые языки перевода**: Русский (`ru`), Английский (`en`)
- **Игра переведена на**: Русский, Английский
- **Управление языком**: автоматически через `ysdk.environment.i18n.lang`, оверрайд `?lang=ru` / `?lang=en` для отладки
- **Возрастной рейтинг**: `0+` (без насилия/азарта), `6+`, `12+`
- **Категории**: 1–2 категории (например: «Аркады», «Казуальные»)
- **Теги**: 3–5 тегов
- **Облачные сохранения**: Да (через `player.setData()` / `player.getData()` с кэшем в `localStorage`) / Нет
- **Отсроченная публикация**: Нет

### Ключевые слова (≤ 100)

```text
[ключ1,ключ2,ключ3 — через запятую, СТРОГО ≤ 100 символов]
```

### Комментарий разработчика (≤ 2048)

```text
Здравствуйте, уважаемая команда модерации Яндекс Игр!

Игра «[НАЗВАНИЕ ИГРЫ]» — это [краткое описание жанра и геймплея].

Технический чеклист интеграции Yandex Games SDK v2:
1. Инициализация SDK: скрипт подключен в <head> через /sdk.js согласно п. 1.1 требований. YaGames.init() и LoadingAPI.ready() вызываются корректно после загрузки ассетов.
2. Геймплейные события: отправляются сигналы GameplayAPI.start() при начале активной игры и GameplayAPI.stop() при паузе, Game Over и перед показом рекламы.
3. Реклама:
   — Межстраничная (Fullscreen Adv): вызывается только на естественных паузах (рестарт уровня, экран поражения) с кулдауном не чаще 1 раза в 60 секунд. Активный геймплей не прерывается.
   — Реклама с вознаграждением (Rewarded Video): инициируется исключительно нажатием игрока на соответствующую кнопку («Возродиться» / «Подсказка»). Награда начисляется строго по коллбэку onRewarded.
   — Звук и анимация глушатся на время показа рекламы.
4. Локализация: поддерживаются русский (ru) и английский (en) языки. Язык выбирается автоматически по ysdk.environment.i18n.lang (п. 2.14 требований).
5. Облачные сохранения: сохраняется рекорд и прогресс игрока (player.setData / getData). Для неавторизованных пользователей работает кэш в localStorage.
6. Пакет и ресурсы: все ассеты (шрифты, текстуры, процедурный Web Audio звук) находятся внутри архива, внешних сетевых запросов нет. Относительные пути (base: './') соблюдены.

Будем рады оперативной обратной связи!
```
