# Сторонние ассеты и пакет подачи на Яндекс Игры (`yandex-assets`)

Памятка по текстам, иконке, обложке, скриншотам и видео для консоли разработчика.
Игровой код (SDK, сейвы, реклама, звук) — в скилле `yandex-games`.

---

## 📦 1. Структура `yandex/`

- `01_general_info.md` — вкладка «Общее» (версия, платформы, ключевые слова ≤ 100, комментарий ≤ 2048)
- `02_description_ru.md` — вкладка «Русский» (название ≤ 50, SEO ≤ 160, короткое ≤ 70, об игре ≤ 1000, как играть ≤ 1000)
- `03_description_en.md` — вкладка «English» (те же 5 полей, настоящий перевод, не копия RU)
- ⚠️ **Все тексты — на ВСЕХ языках (RU + EN)**: пустые вкладки, плейсхолдеры `[...]`, превышение лимитов и EN-копия RU валят валидацию
- `icon_512.png` — строго PNG 512×512
- `cover_800x470.png` — строго PNG 800×470
- `screenshots/` — **ВСЕ скриншоты 16:9 (1280×720)**, включая `mobile_*` (портрет ЗАПРЕЩЁН)
- `video/` — `gameplay_horizontal.mp4` (16:9) + `gameplay_vertical.mp4` (9:16)

Шаблон всех полей: `templates/CONSOLE_FORM.md`.

---

## 🛠 2. CLI скрипты скилла

```bash
# 1. Генерация иконки, обложки, скриншотов (все 16:9) и видео через ffmpeg
python3 scripts/generate_yandex_media.py "НАЗВАНИЕ ИГРЫ" "ПОДЗАГОЛОВОК"

# 2. Проверка текстов RU+EN (лимиты, плейсхолдеры, перевод), размеров и сторон
python3 scripts/validate_yandex_submission.py
```

Шаблоны текстов (`templates/01_general_info.md`, `02_description_ru.md`, `03_description_en.md`)
скопировать в `yandex/` и заполнить все поля на обоих языках, формат `###` + ` ```text ` не менять.
